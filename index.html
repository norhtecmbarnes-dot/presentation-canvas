I need a presentation template in JSON format for Presentation Canvas. Please analyze this presentation and output ONLY valid JSON — no markdown, no explanations.

Required JSON format:
{
  "name": "template name (short)",
  "description": "what this template is for",
  "theme": "dark",
  "slides": [
    "full slide HTML here",
    "full slide HTML here"
  ]
}

Theme must be one of: dark, light, blue, green, red.

EACH slide in the "slides" array MUST:
- Be a COMPLETE <!DOCTYPE html>...</html> document as a single string
- Use 960px wide by 540px tall (16:9), with body { width:960px; height:540px; overflow:hidden; }
- Put all CSS in a <style> tag inside <head> — no external links, no JavaScript
- Use ONLY solid background colors (no gradients), flexbox/grid layout, Arial/Segoe UI fonts
- Be under 3000 characters each
- Use real, meaningful content — never lorem ipsum

Output ONLY the JSON. Do not wrap it in markdown code blocks.

Server Access Information

Start the Server

cd C:\ai\canvas python -m http.server 8080 cd C:\ai\canvas npx serve -l 8080 -s Start-Process python -ArgumentList "-m","http.server","8080","--directory","C:\ai\canvas" -WindowStyle Hidden Start-Process npx -ArgumentList "serve","-l","8080","-s","C:\ai\canvas" -WindowStyle Hidden

Access from This Machine

http://localhost:8080

Access from Other Devices on Your Network

ipconfig | findstr /i "IPv4" http://YOUR_LOCAL_IP:8080

Example: if your IP is 192.168.1.100, use http://192.168.1.100:8080

Note: Make sure your firewall allows inbound connections on port 8080.

Access from Anywhere (Tunnel)

cloudflared tunnel --url http://localhost:8080 ngrok http 8080

These tools create a public URL that tunnels to your local server. Share the generated URL with anyone.

Stop the Server

netstat -ano | findstr :8080 taskkill /PID <PID> /F
